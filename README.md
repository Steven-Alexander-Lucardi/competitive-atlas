# Competitive Atlas

Interactive Capsim competitor analysis for Dynamic Strategy Execution.

The site compares product positions by segment, tracks exact competitor distances across simulation rounds, and includes a Strategic Priorities Lab for customer satisfaction, marketing, and next-round automation.

Data currently includes rounds 0 and 1. This published repository contains the static site only; the original Excel and PowerPoint source files are not included.

## Update a future round

Use the source package retained outside this repository to import the new workbook, rebuild the static files, and replace `data.json`, `app.js`, `style.css`, and `index.html` here.
